# DaniniLans SEO + Visual Checklist

## Metadata

Every page should include:

- title
- description
- canonical URL
- Open Graph image
- Twitter/X preview image
- robots index rules
- structured data where appropriate

---

## Visual system

Required blocks:

- hero section
- comparison table
- video block
- trust/disclaimer card
- diagram/process explanation
- CTA section
- related articles
- internal links

---

## Content structure

Every article:

1. Problem
2. Context
3. AI asks up to 3 clarification questions
4. Human decision layer
5. Explanation / evidence
6. Practical artifact
7. Disclosure
8. CTA

---

## Review content rules

Allowed:
- practical usage
- comparison
- context
- pros/cons
- transparent disclosure

Forbidden:
- miracle claims
- guaranteed health effects
- manipulative before/after framing
- guru urgency language
- fake authority claims

---

## Video guidelines

Video style:
- calm
- premium
- explanatory
- subtitles required
- no aggressive sales style

Recommended duration:
- 60–90s intro videos
- 3–8 minute explanation videos

---

## Iconography

Preferred:
- water
- flow
- hydration
- clean geometry
- premium minimal icons

Avoid:
- neon AI clichés
- exaggerated medical visuals
- cheap affiliate banner style

---

## Technical

Use:
- Next.js App Router
- metadata API
- static generation where possible
- responsive image handling
- multilingual routing
- reusable disclosure components
- reusable comparison tables
